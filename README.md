# Strivers-A2Z-DSA-Solutions

Este repositorio contiene mis soluciones personales para la **[Striver's A2Z DSA Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/)**.

## 📚 Sobre el proyecto

Este repositorio documenta mi progreso mientras resuelvo los problemas de la hoja A2Z de Striver. El objetivo es construir una base sólida en Estructuras de Datos y Algoritmos (DSA). Cada solución incluye mi código y, cuando es necesario, explicaciones adicionales para ayudar a entender el razonamiento detrás de cada enfoque.

## 🗂️ Estructura del repositorio

La estructura sigue fielmente la organización de la hoja original para facilitar su seguimiento:
```
├── 01-learn-the-basics/

│ │ └── ...
│ ├── basic-maths/
│ └── ...
├── 02-sorting-techniques/
├── 03-arrays/
├── ...
└── README.md
```

## 🚀 Cómo usar este repositorio

1.  Navega a la carpeta del tema que te interese.
2.  Busca el archivo correspondiente al problema.
3.  Revisa el código y las explicaciones incluidas.
